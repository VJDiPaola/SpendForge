# Public release checklist

The owner authorized a clean-root history rewrite. Publication remains blocked
until the replacement refs prove that organizer binaries, superseded seed
material, retired proof routes, stale screenshots, secrets, and private-machine
paths are absent from every reachable object.

- [ ] Final lint, typecheck, test, build, and maintained Chromium flows pass.
- [ ] Secret, high-entropy, raw-provider-ID, private-path, and Git-history scans
      find no material exposure.
- [ ] Retired execution routes return 404 on the final protected Preview.
- [ ] All provider mutation and model-execution gates are closed.
- [ ] No Production deployment or Production-only proof claim exists.
- [ ] Screenshots match final copy and visibly label fixture/sandbox/testnet.
- [ ] The final branch is the GitHub default branch.
- [ ] Repository visibility is changed only after the audit above passes.
- [ ] Vercel Authentication remains enabled after GitHub visibility changes.
- [ ] The README states that the repository has no open-source license.

Public visibility does not make this repository open source. Until the owner
chooses a license, the code remains unlicensed/all-rights-reserved. No custom
legal terms are inferred here.
